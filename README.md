# Слои

Браузерная мультиплеерная RPG по авторскому миру книг.
**Сейчас здесь управляемый художественный образец и инженерная основа, не готовая MMO.**
Колыбели не ограничивают мир: поселения, города, внешние маршруты и Слои входят в замысел.

- [Правила агентов](AGENTS.md) — обязательный рабочий цикл и критерии завершения.

- [Дизайн](docs/design/README.md) — визуальный язык, управление, экраны, состояния.

Стек: TypeScript + Canvas 2D + HTML/CSS; Python + FastAPI; целевой игровой транспорт
WebSocket; целевое хранение SQLite. Сейчас FastAPI обслуживает локальный образец, каталог и health endpoint;
игровой WebSocket, симуляция и сохранения ещё не реализованы.

```sh
make build
make serve
# В браузере: http://127.0.0.1:8000
make check
```

Сначала установите инструменты по инструкции запуска. `make check` не устанавливает
зависимости автоматически и не скрывает отсутствующие проверки.

## Границы

Рукописи, приватные сохранения, секреты и чужие игровые ассеты сюда не публикуются.
Дизайн-решения с отметкой `draft` — гипотезы для обсуждения, не утверждённый канон.
Материалы исследования проверены 2026-09-11; 2027 — горизонт планирования, не прогноз.
Публичность репозитория не является разрешением на переиспользование авторского мира.
Выбор лицензии кода и контента остаётся за владельцем.

## Работающий художественный образец

`make serve` открывает на `/` сцену у ворот Кадии. Старый инженерный каталог — `/catalog`.
WASD/стрелки — ходьба, E — ящик рядом, I — снаряжение, F — мишень, Space — выстрел,
R — перезарядка, M — карта, Esc — назад/настройки. Это **локальный образец**, не онлайн:
состояние сбрасывается после перезагрузки. [Направление и границы](docs/design/scene-study.md).
