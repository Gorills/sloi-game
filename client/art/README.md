# Графика художественного образца

Все SVG в этом каталоге созданы программно для `sloi-game` в этом проходе: геометрия,
градиенты, текстуры и детерминированные кроны. Сторонние ассеты, скриншоты коммерческих
игр, скачанные шрифты и страницы рукописей не использовались. ImageGen-коллаж из переписки
не является источником этих ресурсов и не включён в проект.

Это векторная стилизация, а не комплект ручной живописи. Использование и публичное
лицензирование материалов всего проекта определяет владелец репозитория; отдельная
лицензия стороннего автора здесь не заявляется.

Имена совпадают с ID в `loadAssets`. Каждое изображение имеет прозрачность, явные
width/height и viewBox. Позиция ног/основания и размеры размещения заданы в
[описании сцены](../src/scene/world.ts). Фильтры растрируются однократно при загрузке
с коэффициентом 2; на каждом кадре переиспользуются готовые пиксели.

`hunter` / `hunter-back` — передняя/задняя часть тела, `boot` — нога для циклической
ходьбы, `revolver` — отдельное оружие и иконка. Боковая поза ограничена разворотом:
полноценного 8-направленного анимационного набора сейчас нет. Другие ассеты — объекты
окружения и предметы. Контактная тень и окружение рисуются независимо.

Сборщик инлайнит SVG в `dist/scene.html`. Вручную редактируется исходный SVG, не data URL
и не dist. Тест сверяет встроенные байты с исходниками, размеры и отсутствие внешних
ресурсов/скриптов. Сценарий и художественные ограничения — в
[образце 01](../../docs/design/scene-study.md).

`tree.svg` и `shrub.svg` генерируются при сборке из [foliage.py](../../tools/foliage.py)
с фиксированным seed и не коммитятся как тысячи повторяющихся элементов. Все остальные
SVG являются редактируемыми исходниками. Смена seed/палитры требует нового просмотра сцены.
