# ADR 0001 — проверяемая основа без преждевременного движка

Status: accepted

## Контекст

Репозиторий пуст. В предыдущей переписке выбран TypeScript/Canvas + Python/FastAPI,
WebSocket и SQLite. Задача этого PR — правила и дизайн-основа, не реализация мира книг.
Публичный репозиторий не должен содержать рукописи или токены из прежних тестовых трасс.

## Решение

Сохранить выбранный стек, добавить небольшой DOM/Canvas каталог и HTTP-оболочку.
Не импортировать условные боевые и экономические правила технического стенда.
Нормативные инструкции — корневой AGENTS; специализированные процедуры — краткие
Agent Skills; навигация — Markdown с проверкой локальных ссылок.
Исполняемые пороги размера, TS strict и браузерный каталог проверяются в CI.

Использовать два явных профиля browser bootstrap. `url` обязателен в CI;
`embedded` позволяет проверить тот же клиент в ограниченном окружении, но не origin/CSP.
Не считать этот режим заменой production smoke и не ослаблять браузерные политики.

## Альтернатива

Миграция в Phaser/Godot ради тестирования не устраняет ограничения URL-навигации сама
по себе и добавляет непроверенную часть. Пересмотр возможен при измеренном дефиците
Canvas или непропорциональной стоимости инструментов/контента, а не из-за моды.

## Последствия

Два языка и граница wire требуют контрактных тестов. SQLite/один процесс — ограничение
прототипа. Собирать весь клиент в один HTML допустимо для каталога и раннего среза;
это не означает, что весь исходный код должен находиться в одном файле.
Отказ от раннего engine-framework не разрешает создавать самописный универсальный движок.
