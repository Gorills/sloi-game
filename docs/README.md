## Статусы и источники истины

`accepted` — принятая инженерная договорённость; `draft` — обсуждаемая гипотеза;
`reference` — внешние сведения/наблюдения, не приказ к реализации; `template` — форма.
Наличие документа не означает реализации описанной системы.

Код определяет текущее поведение, тесты фиксируют проверяемые ожидания,
[контракты](interfaces.md) — договорённость на границах. При противоречии не исправляйте
одну сторону молча: воспроизведите расхождение и обновите нужные стороны вместе.
Нормативные правила не копируются в отчёты и соседние документы.

Все страницы документации доступны из этого индекса напрямую или через дизайн-индекс.
Исходные файлы навыков перечислены в [маршрутизаторе](agents.md).
