# Маршрутизатор навыков

Status: accepted

Корневой [AGENTS](../AGENTS.md) обязателен всегда. Навык — короткая процедура для
определённой задачи, а не способ загрузить весь справочник в каждую сессию.
Формат основан на [официальной документации](research.md); внешние скрипты не устанавливались.

| Задача | Навык |
|---|---|
| Правила, структура, CI, документация | [repo-foundation](../.agents/skills/repo-foundation/SKILL.md) |
| FastAPI, WebSocket, серверные правила, SQLite | [authoritative-server](../.agents/skills/authoritative-server/SKILL.md) |
| Canvas, интерфейс, ввод, визуальные состояния | [canvas-ui](../.agents/skills/canvas-ui/SKILL.md) |
| Сетевой/браузерный игровой прогон и регрессия | [game-verification](../.agents/skills/game-verification/SKILL.md) |
| Механика, канон, баланс, оценка референса | [game-design](../.agents/skills/game-design/SKILL.md) |

Codex обнаруживает `.agents/skills`; Claude читает root `CLAUDE.md`, который импортирует
AGENTS. Другие клиенты используют адаптер или открывают SKILL.md по маршрутизатору.
Не обещаем универсальное автоматическое обнаружение всеми агентами; запуск из корня
и чтение инструкций надо подтвердить в используемом агентском клиенте.

## Минимальные случаи проверки маршрутизации

«Исправь двойной loot» → authoritative-server + game-verification.
«Текст HUD обрезается» → canvas-ui; не нужен навык SQLite.
«Настрой CI» → repo-foundation; не нужен game-design.
«Измени цену амулета» → game-design, затем сервер/тесты при реализации.
«Поправь опечатку README» → repo-foundation; не запускать игровую симуляцию без причины.

Это ожидаемые случаи, не измеренный benchmark поведения агентов.
Валидатор проверяет упаковку и ссылки, а не качество рассуждения и не следование инструкциям.
