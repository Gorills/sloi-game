# Экраны и состояния

Status: draft

## Карта экранов

```text
вход / возврат персонажа → мир
мир ↔ карта / персонаж / инвентарь / журнал / группа
мир ↔ взаимодействие: торговля / подготовка / проект поселения
мир → поражение → восстановление → мир
любой online-экран → reconnect → восстановленный экран или объяснение ошибки
```

Каталог сейчас демонстрирует визуальные состояния и настройки; эти игровые экраны
ещё не реализованы. Нельзя выдавать статические числа каталога за подключённых игроков.

## Контракты UI

| Поверхность | Что игрок должен понять | Существенные состояния |
|---|---|---|
| HUD | Кто я, состояние, цель, доступное действие, угроза | normal, danger, unavailable, disconnected |
| Подготовка/переход | Цена, риск, маршрут и возможность вернуться | enough, insufficient, pending, accepted, rejected |
| Инвентарь | Что есть, что меняется и почему действие запрещено | empty, selected, full, pending, failure |
| Группа | Союзники, местоположение/цель, статус связи | solo, invited, together, separated, disconnected |
| Поселение | Общая цель и личный вклад | collecting, pending contribution, completed |
| Поражение | Причина, потери, путь возвращения | defeated, restoring, recovered, recovery error |

HUD не обязан постоянно показывать все ресурсы игры. Сведения для следующего решения
остаются рядом с соответствующим действием; подробности — в панели, не в потоке всплывашек.
Важная причина отказа сохраняется до нового решения, не исчезает через секунду.

DOM отвечает за кнопки, поля, панели, диалоги, статус и доступность; Canvas — за мир.
Список заметных целей/взаимодействий должен быть доступен с клавиатуры, не только мышью.
Скрытые серверные данные нельзя включать в accessible DOM для удобства теста.

Одна заметная основная кнопка на решение. Disabled сопровождается причиной.
Pending блокирует повтор на уровне UI, но серверная идемпотентность всё равно обязательна.
Опасные необратимые действия подтверждаются; обычная атака не оборачивается confirm-диалогом.

## Текст и раскладка

Игровые подписи — русские; ID и код — английские. Строки отделяются от правил.
Числа, даты и единицы форматируются последовательно. Подсказки показывают текущие
привязки действий, а не зашитые клавиши. Не использовать неизвестный лор как error message.
Проверять длинные названия, пустой список, крупные числа и масштаб текста 200%.
Узкая раскладка каталога не является доказательством мобильной играбельности.
