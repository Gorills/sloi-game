# Доступность и читаемость

Status: draft

Основания: [WCAG 2.2, Xbox XAG 101/107](../research.md). WCAG применяем к web UI;
соответствие отдельным критериям не означает сертифицированную доступность всей игры.

## Критерии для UI

Обычный текст: контраст минимум 4.5:1, крупный — 3:1; значимые границы и состояния — 3:1.
Цвет не единственный носитель информации. Видимый focus, семантические кнопки,
labels, осмысленный tab order, возврат фокуса после диалога.
Для управляемых элементов цель проекта — минимум 44×44 CSS px. Это выбранный
более просторный размер, а не утверждение, что WCAG 2.2 AA всегда требует 44 px.

Базовый текст каталога 16 CSS px, масштабирование до 200% без исчезновения действий.
`prefers-reduced-motion` отключает декоративную анимацию; опасности остаются заметными.
Не добавлять стробирование. Тряска камеры отключаема, смысл не передаётся только звуком.
Не делать чёрный на почти чёрном ради «мрачной атмосферы».

## Что автотест не доказывает

Проверка пар токенов не проверяет текст на реальном фоне сцены.
DOM accessibility tree не делает автоматически понятной Canvas-карту.
Скриншот не доказывает удобство управления, утомляемость или различимость звука.

На первом срезе: клавиатурный проход, 200% текста, тёмная/светлая сцена,
несколько участников, отключённый звук, reduced motion и разрыв соединения.
Проверить с людьми; не объявлять полную поддержку screen reader до реального сценария.

## Foundation

Каталог предоставляет семантические кнопки/поля, status, диалог с возвратом фокуса,
масштаб текста и переключатель декоративного движения. Игрового remap пока нет.
Тесты проверяют только реально реализованные поверхности.
