# Система управления

Status: draft

Цель первого среза — desktop, клавиатура и мышь. Gamepad и touch не считаются
поддержанными до отдельного прототипа и реальных проверок.

## Предлагаемые действия

| Действие | Начальная привязка | Поведение |
|---|---|---|
| Движение | WASD / стрелки | Удержание; диагональ не даёт дополнительную скорость |
| Выбор цели | ЛКМ по цели / F | F перебирает доступные цели; не забирает Tab у UI |
| Обычная атака | Space | Нужна допустимая цель; удержание/toggle обсуждаются отдельно |
| Взаимодействие | E / кнопка | Контекст и причина недоступности видимы заранее |
| Способности | Q, R | Не назначать несуществующие способности ради пустых слотов |
| Карта / инвентарь / журнал | M / I / J | Повтор закрывает свою панель |
| Метка группе | G | Pointer и доступный вариант через список/клавиатуру |
| Меню/назад | Esc | По одному уровню интерфейса, не глобальный сброс |

Это будущая раскладка, а не уже реализованный обработчик игры.
Привязки задаются действиям, не размазаны по рендереру и экранным компонентам.
Переназначение показывает конфликты, поддерживает возврат defaults и сохраняется локально.
Нельзя требовать сочетания/быстрое многократное нажатие там, где достаточно одного действия.

## Приоритет ввода

Текстовый ввод → активный диалог → открытая панель → игровой мир.
Tab/Shift+Tab перемещают UI-фокус, Enter/Space активируют сфокусированную кнопку.
Esc закрывает верхний диалог, затем панель, затем снимает цель, затем открывает меню.
Закрытый диалог возвращает фокус на вызвавший элемент. Фокус никогда не остаётся в скрытой панели.
В открытом диалоге Space не стреляет, а печать WASD в чате не двигает персонажа.

События `blur`, скрытие вкладки, потеря pointer capture и отключение очищают удержанные
действия. После reconnect не воспроизводится накопленная очередь атак/движений.
Не перехватывать системные Ctrl/Cmd-комбинации браузера. `preventDefault` только
для обработанного действия в игровом контексте, не для всего документа.

## Мультиплеер

Меню не ставит общий мир на паузу — это сообщается явно. Сетевой статус различает
подключение, reconnect, offline и ошибку сессии. Локальная UI-реакция отделена от
серверного результата. Без связи запрещены новые экономические операции.

Основание: [Xbox XAG 107](../research.md). Локальная игра не может глобально замедлять
общий мир для одного игрока; вместо этого проверяем remap, toggle и читаемые окна реакции.
