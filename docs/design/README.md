# Дизайн-основа

Status: draft

Это ориентиры и заготовки. Они не объявляют утверждёнными арт-стиль, управление и баланс.
Токены и каталог дают место для совместной проверки до массового производства UI/ассетов.
[Визуальная приёмка](visual-acceptance.md) — принятый обязательный процесс, независимо
от чернового статуса художественного направления. V0.1 визуально не принят.

| Область | Документ / артефакт |
|---|---|
| Самооценка качества и запрет сдачи слабого визуала | [Визуальная приёмка](visual-acceptance.md) |
| Визуальная идентичность, сцены, движение, звук | [Визуальный язык](visual.md) |
| Клавиатура/мышь, приоритеты, remap, отключение | [Управление](controls.md) |
| Экраны, HUD, состояния и обратная связь | [Интерфейсы](interfaces.md) |
| Читаемость, фокус, масштаб и доступность | [Доступность](accessibility.md) |
| Проверка интереса и удобства | [Плейтест](playtesting.md) |
| Цвет, размеры, интервалы, движение | [Токены](../../client/design/tokens.json) |
| Рабочий этюд графики и управления (`/scene`) | [Предместье V0.1](scene-study.md) |
| Исполняемый каталог компонентов | [HTML](../../client/index.html), запуск `make serve` |
| Основания и ограничения референсов | [Исследование](../research.md) |

Каждая новая карточка системы использует [шаблон](../templates/system.md): цель игрока,
вход, действия, состояния, обратная связь, кооперация, ошибки, канон, тесты и открытые решения.
Пустые разделы называются открытыми, а не заполняются выдуманным балансом.
