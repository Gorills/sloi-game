# Канон и игровые адаптации

Status: reference

## Работа с источниками

У автора есть четыре рукописи: `One(4).docx`, `Two(2).docx`, `Three(1).docx`,
`Four(1).docx`. Они переданы в переписке и намеренно не добавлены в публичный Git.
Ни эта страница, ни прежний прототип не заменяют полного канона.
Без доступа к нужному фрагменту помечать правило `NOT VERIFIED` и не изобретать подробности.

Три раздельных вида записи: факт/событие из текста; объяснение или предположение
персонажа; предложенная игровая адаптация. Реплики ненадёжного рассказчика
не становятся автоматически законом мира. Противоречия сохранять до решения автора.

Слова `Город`, `город/поселение`, `Колыбель`, `Разлом`, `Слой` сохранять различимыми.
Не решать вопрос их полного взаимного соответствия редакторской заменой терминов.

## Карточка будущего решения

`ID → тема → источник (книга/глава/фрагмент) → тип свидетельства → формулировка →
неопределённость → предлагаемая адаптация → одобрение автора → тестовый сценарий`.

Особенно нужны карточки смерти/возрождения, расхода осколков вне зоны Колыбели,
получения способностей, межслойной торговли и возможного управления поселением.
Книжные сроки и цены не переносить в баланс автоматически.
