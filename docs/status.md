# Состояние проекта

Status: accepted

## Foundation / 2026-09-11

В репозитории до этой задачи не было игрового кода. Предыдущий технический стенд из
переписки не импортирован: его условные правила не являются утверждённым дизайном.

| Область | Сейчас |
|---|---|
| Инструкции и навыки | Добавлены; фактическое чтение зависит от агентского клиента |
| Структура и quality gates | Ограничения файлов/функций, ссылки, навыки, типы, тесты |
| UI | Каталог токенов и состояний + локальный [графический этюд](design/scene-study.md) |
| FastAPI | Каталог `/`, художественный этюд `/scene`, проверка `/health` |
| WebSocket, игровая симуляция, SQLite | Проектные ограничения описаны, реализации нет |
| Геймплей и баланс | Черновик первого среза, пользовательских плейтестов нет |
| Защита main | См. отдельный фактический статус в [governance](governance.md) |

## Художественный образец V0.1

По отдельному запросу владельца добавлена локальная сцена графики/управления.
Она не заменяет S1, не выдаёт локальные действия за сетевую игру и не импортирует
условные правила прошлого стенда. Художественное направление ожидает оценки автора.

## Следующий ограниченный этап S1

Два игрока входят в одну локацию, видят движение друг друга, выходят и возвращаются
к сохранённым персонажам. Один сервер, одна карта, без боевой системы и экономики.

Приёмка: реальные два браузера, native WebSocket, серверные проверки скорости/границ,
ошибочные команды, потеря фокуса, обрыв связи, новый процесс сервера и дальнейшее движение.
Перед реализацией уточнить wire/session/storage решения по [контрактам](interfaces.md).
Не выдавать протокол из этой страницы за уже существующий API.

## Не принимаем сейчас

Публичный релиз, монетизацию, постоянную смерть, PvP, бесшовный мир, гильдейское
управление городом, мобильный паритет, посещение верхних Слоёв и массовые рейды.
Это не запрет будущего развития, а граница текущей работы.
